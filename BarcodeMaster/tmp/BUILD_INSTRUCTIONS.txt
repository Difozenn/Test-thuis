Project Datalog - Build Instructions for Windows

IMPORTANT: The executable must be built on Windows, not in WSL/Linux.

Prerequisites:
1. Install Python 3.8+ for Windows from python.org
2. Install required dependencies:
   pip install pyinstaller tkinter flask werkzeug jinja2 waitress pandas openpyxl xlrd xlwt xlsxwriter PyPDF2 pdfplumber pyserial requests psutil pyodbc pillow

Building the Executable:

1. Open Windows Command Prompt or PowerShell
2. Navigate to the project directory:
   cd C:\Users\Rob_v\Desktop\Test-thuis\BarcodeMaster

3. Build with console output (for debugging):
   python build_exe.py --console

4. Build without console (for production):
   python build_exe.py

The executable will be created in the dist/ folder as ProjectDatalog.exe
