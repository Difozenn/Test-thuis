# BarcodeMatch System Interconnection Map

## 🧠 **Core System Overview**
BarcodeMatch is a secondary application that integrates with BarcodeMaster for barcode data processing. It operates as a dependent system that receives triggers and processes XLSX files generated by BarcodeMaster.

---

## 🔄 **Session Management System**

### **Core Session Types** (BarcodeMatch Only)
1. **XLSX_UPDATED**: Auto-triggered when BarcodeMaster generates _updated XLSX files
2. **MANUAL**: User-initiated via right-click menu in database panel

**❌ NOT SUPPORTED**: SCANNER session type (BarcodeMaster exclusive)

### **🔗 Session Dependencies**

#### **1. Auto-Trigger Workflow**
- **Trigger Source**: BarcodeMaster file generation (_updated XLSX files)
- **Detection**: File system monitoring or API callbacks
- **Session Creation**: Automatic XLSX_UPDATED session start
- **Session End**: User sends AFGEMELD event

#### **2. Manual Workflow**
- **Trigger Source**: Right-click menu in database panel
- **Session Creation**: User-initiated MANUAL session
- **Session End**: User action or timeout

## 🔗 **BarcodeMaster Integration**

### **🔗 API Dependencies**

#### **1. Session Management APIs**
- **Session Start**: `POST http://localhost:5001/session/start`
  - Creates XLSX_UPDATED or MANUAL sessions
  - Validates work hours before session creation
  - Returns session_id for tracking

- **Session End**: `POST http://localhost:5001/session/end`
  - Ends active session with work time calculation
  - Updates session work_duration_minutes

- **XLSX Updated**: `POST http://localhost:5001/session/xlsx_updated`
  - Special endpoint for auto-triggered sessions
  - Changes user status to BEZIG (working)

#### **2. Work Hours Validation**
- **Dependency**: Uses BarcodeMaster work hours configuration
- **Validation**: Cannot start sessions outside work hours
- **Schedule**: Follows BarcodeMaster per-day schedule
  - Monday-Thursday: 07:30-16:00
  - Friday: 07:30-15:00
  - Break: 12:00-12:30

#### **3. Configuration APIs**
- **Work Hours**: `GET /api/settings/work-hours`
- **User Settings**: Various configuration endpoints
- **Status Updates**: Real-time session status synchronization

## 📊 **Data Flow System**

### **🔗 File Processing Workflow**

#### **1. XLSX_UPDATED Trigger**
```
BarcodeMaster generates _updated XLSX file
    ↓
BarcodeMatch detects file creation
    ↓
Auto-creates XLSX_UPDATED session
    ↓
User processes barcode data
    ↓
User sends AFGEMELD event
    ↓
Session ends with work time calculation
```

#### **2. Manual Session Workflow**
```
User right-clicks in database panel
    ↓
Manual session menu appears
    ↓
User selects session type/project
    ↓
MANUAL session created
    ↓
User performs manual processing
    ↓
Session ends via user action
```

### **🔗 Data Synchronization**

#### **1. Session Data**
- **Storage**: BarcodeMaster central database
- **Synchronization**: Real-time via API calls
- **Fields**: session_id, user, start_time, end_time, session_type, work_duration_minutes

#### **2. Project Data**
- **Source**: BarcodeMaster project management
- **Access**: Read/write via BarcodeMaster APIs
- **Integration**: Project status updates, completion tracking

## ⚠️ **Critical Dependencies & Constraints**

### **🔗 BarcodeMaster Dependencies**

#### **1. Required BarcodeMaster Services**
- **Database API**: Must be running on port 5001
- **Work Hours Configuration**: BarcodeMatch inherits work schedule
- **User Configuration**: BarcodeMatch users must exist in BarcodeMaster config
- **Session Management**: All session data stored in BarcodeMaster database

#### **2. Session Type Constraints**
- **❌ SCANNER**: NOT allowed in BarcodeMatch
- **✅ XLSX_UPDATED**: Auto-triggered only
- **✅ MANUAL**: User-initiated only
- **⚠️ Validation**: Session creation fails if wrong type attempted

#### **3. Work Hours Constraints**
- **Inheritance**: Cannot override BarcodeMaster work hours
- **Validation**: Sessions blocked outside BarcodeMaster work schedule
- **Updates**: Work hours changes require BarcodeMaster restart/cache refresh

## 📝 **Development Guidelines**

### **Before Making Changes:**
1. **Check BarcodeMaster Compatibility**: Ensure changes don't break integration
2. **Verify Session Type Restrictions**: Only XLSX_UPDATED and MANUAL allowed
3. **Test API Integration**: Verify all BarcodeMaster API calls still work
4. **Review Work Hours Logic**: Ensure inherits BarcodeMaster schedule

### **Integration Points to Maintain:**
1. **Session API Calls**: Keep compatible with BarcodeMaster endpoints
2. **User Configuration**: Maintain mapping to BarcodeMaster users
3. **Work Hours**: Always inherit from BarcodeMaster, never override
4. **File Processing**: Maintain compatibility with BarcodeMaster file formats

### **Forbidden Changes:**
1. **❌ SCANNER Session Type**: Never implement SCANNER in BarcodeMatch
2. **❌ Independent Work Hours**: Never create separate work hour logic
3. **❌ Bypass API**: Never directly access BarcodeMaster database
4. **❌ Session Validation Override**: Never bypass BarcodeMaster work hours validation
