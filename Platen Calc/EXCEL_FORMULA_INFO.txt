EXCEL FORMULA IN EXPORTED FILES
================================

The "Saldo (m²)" column now contains an Excel formula that automatically recalculates when you change values.

FORMULA:
--------
Saldo = Stock + In Bestelling - (Bruto + Veiligh.)

In Excel terms (for row 2):
=F2+G2-(D2+E2)

WHERE:
------
Column D = Bruto (m²)       - Material needed after accounting for waste
Column E = Veiligh. (m²)     - Safety margin to keep in stock
Column F = Stock (m²)        - Current stock level
Column G = In Bestelling (m²) - Amount already ordered (YOU CAN EDIT THIS!)
Column H = Saldo (m²)        - Automatically calculated result

HOW TO USE:
-----------
1. Export the calculation to Excel
2. Open the Excel file
3. Change any value in the "In Bestelling (m²)" column (light blue background)
4. The "Saldo (m²)" column will automatically update!

COLOR CODING:
-------------
- RED: Negative value (you need to order more)
- GREEN: Positive value (you have surplus)
- The colors update automatically when the Saldo changes!

EXAMPLE:
--------
If Stock = 100, Bruto = 80, Veiligh. = 10, In Bestelling = 0
Then Saldo = 100 + 0 - (80 + 10) = 10 (GREEN - surplus)

If you change In Bestelling to 20:
Then Saldo = 100 + 20 - (80 + 10) = 30 (GREEN - more surplus)

If Stock = 50, Bruto = 60, Veiligh. = 10, In Bestelling = 0
Then Saldo = 50 + 0 - (60 + 10) = -20 (RED - need to order)

If you change In Bestelling to 25:
Then Saldo = 50 + 25 - (60 + 10) = 5 (GREEN - now OK!)
